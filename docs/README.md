# 프로젝트 문서

이 폴더는 `0916-project` 프로젝트의 문서를 관리하는 공간입니다.

## 프로젝트 구성

- `frontend/`: Vite 기반 프론트엔드 애플리케이션
- `backend/`: Node.js 백엔드 서버
- `package.json`: 루트 개발 명령 및 공통 의존성 설정

## 개발 서버 실행

프로젝트 루트에서 다음 명령을 실행합니다.

```bash
npm run dev
```

실행 후 프론트엔드는 `http://localhost:5173`, 백엔드는 `http://localhost:3000`에서 확인할 수 있습니다.
